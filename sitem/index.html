Nasıl bağlanırım?

Minecraft'ı aç, Çok Oyunculu bölümüne gir, Sunucu Ekle de ve yukarıdaki IP adresini yapıştır.

Hangi sürüm?

Sunucu Java sürümü 1.21.6'da çalışıyor. Oyunu Java Edition 1.21.6 ile açmalısın. Bedrock sürümüyle (telefon, konsol) girilemez.

Sunucuya nasıl girilir?

TLauncher ile ya da başka bir launcher ile girebilirsin. Önemli olan oyunu Java 1.21.6 sürümüyle açmak.

  1. Sürümü seçLauncher'ı aç ve sürüm listesinden Java 1.21.6 sürümünü seç.
  2. Oyunu başlatOyna butonuna bas ve Minecraft'ın ana menüsüne gelmesini bekle.
  3. Çok Oyunculu'ya girAna menüde "Çok Oyunculu" butonuna tıkla.
  4. Sunucu ekle"Sunucu Ekle" butonuna bas. Sunucu adına istediğin ismi yaz, örneğin SurvivalCraft.
  5. IP adresini yapıştırSunucu adresi kısmına playsurvivalcraft.aternos.me yaz ya da kopyalayıp yapıştır, sonra "Bitti" de.
  6. KatılListeden sunucuyu seç ve "Sunucuya Katıl" butonuna bas. İyi eğlenceler!
Sunucu Java sürümü olduğu için Bedrock ile (telefon, konsol, Windows 10 Bedrock) girilemez. Sunucuya giremiyorsan sunucu kapalı olabilir. Aternos sunucuları kimse açmadığında kapanabilir, sunucu açılınca tekrar dene.

Bilgisayar hâlâ aynı, ama artık Windows 10 LTSC kullanıyor. 11 yaşında TLauncher'ı keşfetti ve hâlâ TLauncher ile oynuyor. Bilgisayarında 3 oyun var: Among Us, Roblox ve Minecraft.
